# Ari Vega — Personal Portfolio

Five-page portfolio built with HTML, custom CSS, JavaScript, Bootstrap 5.3.3, and JSON. Includes category filtering, project search, and a persistent light/dark theme.

The deployment copy keeps its assets beside index.html. Project data is loaded from projects.json using fetch().

## Run locally

Run `python -m http.server 8000` in this folder, then visit http://localhost:8000.

## Pages

Home, Skills, Experience / Education, Projects, and Contact.

Bootstrap is included locally under its MIT license, with notices preserved.
